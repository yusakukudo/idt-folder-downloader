# 🌐 idt-dlp — Multi-Platform Audio Downloader Suite (`all_platform`)

`idt-dlp` is a fast, asynchronous multi-platform downloader for ISKCON Desire Tree audio folders, featuring dark/light themes, customizable save locations, automatic URL normalization, and full logo branding.

## 📁 What's Included in `all_platform/`

### 📱 1. Android Mobile App
- **Features**: Folder picker with "📁 Browse" button, custom download directory selection, default public `Downloads/IDT_Downloads` storage, `idt-dlp` logo and title, Dark/Light mode toggle, and live progress dashboard.
- **Source Code**: [`IDT_Downloader_Android_Project/`](./IDT_Downloader_Android_Project/)

### 🍏 2. macOS Desktop App
- **Features**: Standalone `.app` with native macOS `icon.icns` dock icon, header logo, folder browse picker, and async download workers.

### 🪟 3. Windows Desktop App
- **Features**: Standalone Windows PE `.exe` with `icon.ico`, header logo, folder browse picker, and async download engine.
