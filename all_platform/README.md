## 📁 Local Files in `all_platform/`

### 🍏 1. macOS Desktop App
- **Local Location**: [`IDT Downloader.app`](./IDT%20Downloader.app)
- **Format**: Native standalone macOS Application bundle
- **Launch**:
  ```bash
  open "all_platform/IDT Downloader.app"
  ```

### 🪟 2. Windows Desktop App
- **Local Executable**: [`IDT_Downloader_Windows_Executable/IDT_Downloader_Windows.exe`](./IDT_Downloader_Windows_Executable/IDT_Downloader_Windows.exe)
- **Local Zip Archive**: [`IDT_Downloader_Windows.zip`](./IDT_Downloader_Windows.zip)
- **Format**: Standalone Windows PE `.exe` executable (built on Windows Server 2022 runner)
- **Launch**: Double-click `IDT_Downloader_Windows.exe` on any 64-bit Windows machine.

### 📱 3. Android Mobile App
- **Local APK**: [`IDT_Downloader_Android.apk`](./IDT_Downloader_Android.apk)
- **Format**: Standalone compiled Android APK (Debug/Universal)
- **Install**: Transfer `IDT_Downloader_Android.apk` to any Android device running Android 7.0+ (API 24+) and tap to install.
- **Source Code**: [`IDT_Downloader_Android_Project/`](./IDT_Downloader_Android_Project/)
